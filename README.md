# E2B Sandbox Demos

## Use Cases

| Demo | Use case |
| --- | --- |
| Code Interpreter | Execute Python code in an E2B Code Interpreter sandbox and reuse sandbox state. |
| Browser CDP | Launch browsertool in a sandbox and expose a CDP WebSocket endpoint for Playwright. |
| BrowserUse Agent | Run BrowserUse agents in an E2B browser sandbox, including session reuse. |
| LangChain Browser Agent | Control an E2B browser sandbox through LangChain tools for navigation, screenshots, and cleanup. |
| Browser Studio | Provide a browser-focused API and frontend product shell. |
| PDF-to-Markdown LangChain | Build a document-conversion template, then use a LangChain agent to convert PDFs to Markdown in E2B. |
| Mastra Code Agent | Use E2B from a Mastra agent through sandbox, code, file, command, and cleanup tools. |
